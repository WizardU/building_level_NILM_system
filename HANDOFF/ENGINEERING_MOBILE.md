# Engineering & mobile delivery (YSB)

**Scope:** M3 FastAPI backend/API + M5 Uni-app mobile H5.  
**Primary ownership:** mobile client; shared backend/API integration.  
**Status:** H5 complete and verified; native builds deferred; backend is the local SQLite/ONNX demo backend.

## 1. What was delivered

### 1.1 Backend (M3, shared ownership)

| Item | Actual implementation |
|---|---|
| Framework | FastAPI, JWT auth, Pydantic schemas |
| Routers | 9: `auth`, `buildings`, `meters`, `measurements`, `events`, `disaggregation`, `appliances`, `analytics`, `datasets` (report's 8 + WHITED `datasets`) |
| Contract | `openapi/NILM.json`, **38 paths**; generated by `scripts/export_openapi.py` |
| Persistence | **SQLite** (`backend/nilm.db`), SQLAlchemy ORM, seed/replay data |
| Cache | SQLite-backed disaggregation cache, keyed by meter + window + model version |
| Inference | ONNX Runtime, 5 appliance models loaded from `ml/checkpoints/*.onnx` |
| Replay | `adapters/replay/` pushes UK-DALE samples into `/measurements/upload` |
| Checks | `scripts/smoke_api.py` — **21/21 pass** |

> **Report wording discrepancy:** the progress report says "SQLite/PostgreSQL + Redis caching" and "18.64 ms".
> In this local branch there is **no Redis and no PostgreSQL**; the backend is SQLite-only. Current measured
> inference is roughly **40–75 ms** per request on this laptop (43.72 ms and 74.56 ms in two smoke runs), not a
> guaranteed 18.64 ms. Correct the report or add the missing services before claiming them.

### 1.2 Mobile H5 (M5, primary ownership)

- Uni-app / Vue 3 H5 client in `mobile/`
- 5 pages: `login`, `home` (Monitor), `appliances` (Devices), `analytics` (Analytics), `profile`
- 4-tab bar: Monitor / Devices / Analytics / Profile
- English-only UI; appliance labels mapped by `utils/labels.js`
- Same REST contract as Web; auth token + 401 redirect in `utils/api.js`
- 2-hour window rounded to the current minute so the backend cache is used
- H5 verified locally; **native iOS/Android builds are not done**

Known chart fix in this branch: `mobile/src/components/PowerChart.vue` now sets the uCharts
`yAxis.title = 'W'` (previously the renderer showed `undefined` as the axis title).

## 2. How to run

```powershell
# backend
cd NILM\backend
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000

# web (Jin's client, useful for comparison)
cd NILM\web
$env:TEMP="$PWD\..\report_build\tmp"; $env:TMP=$env:TEMP
npm run dev -- --host 127.0.0.1 --port 3000

# mobile H5
cd NILM\mobile
npm run dev:h5
```

The mobile `API_BASE` is in `mobile/src/utils/config.js`:

```js
export const API_BASE = 'http://127.0.0.1:8000/api/v1'
```

For a phone on the same LAN, replace `127.0.0.1` with the laptop LAN IP.

Login: `admin / admin123` (demo seed).

## 4. Known gaps / do not overclaim

1. **Redis / PostgreSQL not implemented.** SQLite only; report must be corrected or services added.
2. **Latency 18.64 ms not reproduced.** Current local runs are 40–75 ms; report should use a range or a new measurement.
3. **Modbus/MQTT is a stub.** Only replay is real (`adapters/modbus_mqtt/` is not on the verified path).
4. **Native mobile builds not done.** H5 is complete; iOS/Android packaging is W7.
5. **No pytest/CI/Alembic.** Only the 21-check smoke script; no unit tests, no GitHub Actions, no migration chain.
6. **Docker backend still mounts `ml/`**; it is a dev compose, not a self-contained production image.
7. **Push notifications / offline mode** are not implemented on mobile.
