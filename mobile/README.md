# NILM Uni-app Mobile Client

Basic cross-platform client (login, live power, appliances). **Not part of the defense demo path** — Web console is the primary demo.

## Setup

1. Open this folder in HBuilderX, or use `@dcloudio/vite-plugin-uni`.
2. Set `API_BASE` in `utils/config.js` to your backend (e.g. `http://<LAN-IP>:8000/api/v1`).
3. Run to browser / Android for smoke test against the FastAPI backend.

Default login: `admin` / `admin123`.
